Senthil.Comp

A complete 32-bit computing platform from scratch!

Introduction

Senthil.Comp is an attempt at creating a complete 32-bit computing platform from scratch, purely in software. The following are the core components of this project.

  • Instruction Set Architecture
  • Virtual Machine
  • Assembly language specification + an assembler
  • C-like high-level language + a compiler
  • Operating System Kernel
