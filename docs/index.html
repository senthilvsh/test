Senthil.Comp

A complete 32-bit computing platform from scratch!

Introduction

Senthil.Comp is an attempt to create a complete 32-bit computing platform from scratch

The core components of this project include:

  • Instruction Set Architecture
  • Virtual Machine
  • Assembly Language
  • High-Level Language
  • Operating System Kernel

Inspiration

Why would anyone even want to attempt something like this? Don't I have something more important or commercially viable to work on? For me, the answer splits into two equally compelling drives:

The Allure of the Bare Metal

There is a rare, pure engineering joy in taking apart the world and putting it back together just to see how it ticks. Rebuilding a stack from scratch completely eliminates the legacy hardware baggage, commercial compromises, and missing documentation found in real-world systems. It gives you absolute architectural freedom to answer the ultimate question: how deep does the software rabbit hole actually go?

A Sandbox for Pure Logic

Beyond the thrill, there is a deep fascination with core operating system concepts like task scheduling, memory management, and file system topologies. I can cleanly visualize how a naive implementation would work in my head.

But studying real-world kernels on modern x86/ARM hardware is incredibly hostile; you are instantly buried under decades of legacy quirks, out-of-order execution workarounds, and hyper-complex security mitigations. By creating my own custom virtual machine from scratch, I bypass the real-world noise entirely. I get a pristine, mathematically sterile sandbox to isolate and play with pure system architecture logic.

This project is a pure passion project, educational tool, and engineering sandbox. It has absolutely zero commercial ambitions, production utility, or real-world stability goals. It is built strictly for the joy of solving hard problems and playing on the bare metal.

The Journey

Building a complete computing stack from scratch is bound to be a wild, chaotic ride, and I plan to document every single mile of it. I will be capturing the entire journey step-by-step in the dedicated series of posts below. Every design idea, implementation strategy, boneheaded mistake, frustrating bug, breakthrough "aha!" moment, and incremental milestone will be laid out in the open. Whether it succeeds spectacularly or crashes in a ball of virtual smoke, you will see exactly how it happened.
